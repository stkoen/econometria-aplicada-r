# Estado del repositorio

Repositorio: https://github.com/stkoen/econometria-aplicada-r

Los seis ejercicios, sus bases de distribución, informes, figuras y código
se cargaron en la rama main. El repositorio permanece privado. Las
comprobaciones remotas se documentan en COMPROBACIONES.md.

## Antes de hacerlo público

Las bases docentes no aportan una licencia explícita de redistribución.
Su estado se documenta en FUENTES.md; el repositorio privado permite
conservar el proyecto completo mientras se resuelve qué datos acompañarán
a una versión pública. No se asigna a terceros una licencia inventada.

Las entregas originales se conservan fuera del repositorio. El manifiesto
distingue sus hashes de las copias XLSX con metadatos reducidos.
METADATOS.md describe esa revisión.

## Presentación profesional

El README destaca tres aplicaciones y mantiene acceso a los seis informes.
Cuando el acceso público esté resuelto, se podrá compartir su URL en el CV
y en LinkedIn. El proyecto anterior de Ciencia de Datos conserva su propio
repositorio y no se mezcla con estos ejercicios.
