# Preparación de publicación

El ZIP contiene la carpeta raíz `econometria-aplicada/`. Para un repositorio de
código se utiliza su contenido descomprimido, no solo se sube el archivo ZIP.

1. Leer el README y los seis informes generados, en particular las diferencias
   entre cifras reproducidas y ampliaciones.
2. Crear un repositorio y cargar la carpeta raíz conservando su estructura.
3. Ejecutar las comprobaciones locales y, después de subirlo, comprobar el
   flujo de GitHub Actions. Su ejecución remota está preparada pero todavía
   no ha ocurrido.
4. El repositorio no incluye una licencia abierta inventada para el código
   propio ni para las bases docentes. Las atribuciones y el estado de las
   licencias recibidas se documentan en FUENTES.md.
5. Cuando exista la URL del repositorio, se puede añadir a Destacados de
   LinkedIn con una descripción de los métodos y un enlace al README. La
   revisión del proyecto de crédito de otro curso se realiza por separado.

No se han publicado archivos ni modificado perfiles externos desde este
paquete. Se conservan los originales fuera del repositorio; sus hashes se distinguen
de las copias XLSX con metadatos reducidos. METADATOS.md describe la revisión.
