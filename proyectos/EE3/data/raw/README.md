La base no se redistribuye en este repositorio. `Rscript run.R` descarga
`airfare.RData` de una revisión fija del repositorio oficial de `wooldridge`,
comprueba su hash y la guarda aquí como caché. Se requiere conexión en la
primera ejecución. No se sustituyen los datos originales por datos simulados.

Fuente y hashes: `docs/FUENTES.md`.
